# OdontoSoft Millennium (GB Systems)

- **URL**: https://gbsystems.com/os/ (precios: https://gbsystems.com/os/promo.htm)
- **Fecha de investigación**: 2026-10-01

## Problema que resuelve

Programa de gestión clínica y comercial odontológica, instalado en PC, con terminología argentina.

## Usuarios objetivo

Dentistas y clínicas de Latinoamérica ("más de 3000", según el sitio).

## Features detectadas

- Agenda de citas y llamados; SMS masivos para controles y confirmaciones
- Odontogramas gráficos y periodontograma (mencionado)
- Empresas de salud / prepagas / aseguradoras
- Módulo web opcional

## Pricing

USD, licencia única: Basic 299; Single-user 390; Multi 5: 799; Multi 10: 1.199. Suscripción mensual: 35 / 65 / 99 USD. Módulo web opcional USD 120. Demo disponible; sin trial formal (según promo.htm).

## Posicionamiento

Software veterano de escritorio, soporte por email/chat/remoto, manual y videos en español.

## Diferenciadores

Licencia perpetua o mensual; operación local; sin dependencia de internet (inferencia, no publicado).

## Notas del investigador

Compatibilidad declarada con Windows XP a 10 (sitio desactualizado). Probablemente sin reserva online salvo módulo web (no detallado).
