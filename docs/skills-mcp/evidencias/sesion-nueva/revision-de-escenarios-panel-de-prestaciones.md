## Bordes sugeridos
1. **403 antes que 422 (D208)**. GIVEN la recepcionista en la pantalla; WHEN crea «Blanqueamiento» con duración 47 y pulsa «Guardar»; THEN la API responde `403` con `codigos` `["RN-AU-05"]`, la interfaz muestra el mensaje de permiso y **no** el de `RN-AG-01`. Aplica porque el control de acceso se evalúa antes que la validación. (RN-GL-02, D208)
2. **Error de red al guardar**. GIVEN la odontóloga con el panel de alta abierto y la API caída (o `5xx`); WHEN pulsa «Guardar» con datos válidos; THEN el panel muestra «No se pudo conectar con el servidor. Probá de nuevo en unos minutos.», conserva lo escrito, el botón vuelve a habilitarse y la tabla no cambia. (design T6 clase 6, T11)
3. **Guardar sin cambios** (H1). GIVEN la odontóloga editando «Limpieza» sin tocar nada; WHEN pulsa «Guardar»; THEN el panel se cierra y la API no recibió ningún `PATCH`. (design T9)
4. **Cargando** (H2). GIVEN la respuesta de `GET /prestaciones` retenida; WHEN se abre la pantalla; THEN se ve «Cargando prestaciones…» y ninguna fila hasta que llega la respuesta. (design T11)
